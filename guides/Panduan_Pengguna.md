# Panduan Pengguna — Lampu Solar Karak

Alamat aplikasi: **https://globalsentrum.github.io/solar-light-app/**
(Pasang ke skrin utama: Android → Chrome ⋮ → *Install app*. iPhone → Safari → Share → *Add to Home Screen*.)

ID tiang: **SSL001 … SSL123** (cth. SSL034). Carian boleh guna nombor sahaja, cth. `34`.

---

## A. Untuk PASUKAN (Team)

**Log masuk:** buka ikon *Lampu Solar* → **Sign in with Google** → **Teruskan ke aplikasi**. Log masuk kekal ~30 hari.

### 1. Lihat kerja esok
Tab **📋 Jadual** dibuka pada **Esok**: hanya tiang yang dirancang oleh admin, disusun ikut chainage, dengan aktiviti
(cth. *Trial Pit*) jika ditetapkan. Tab **Hari ini** untuk kerja hari ini, **Semua** untuk senarai penuh 123 tiang.
Pelan kerja juga boleh dilihat tanpa line (disimpan dalam telefon).

### 2. Ambil gambar ikut aktiviti
Ketik tiang. Gambar disusun dalam 3 aktiviti:

| Aktiviti | Jenis gambar | Minimum |
|---|---|---|
| **Pegging** | Pegging | 1 |
| **Trial Pit** (📐 Dalam 1.5m, lebar 1m, panjang 1m) | Korek | 1 |
| | Lebar — **masukkan ukuran (m)** | 1 |
| | Panjang — **masukkan ukuran (m)** | 1 |
| | Dalam — **masukkan ukuran (m)** | 1 |
| **Installation** | Progress pemasangan | **4** |
| | Siap dipasang (siang) | 1 |
| | Ujian lampu (malam) | 1 |

1. Ketik **📷 Ambil gambar** (atau **+ Tambah gambar**) → **📷 Kamera** atau **🖼️ Galeri**.
2. Tunggu "Mendapatkan lokasi GPS…" (maksimum 15 saat). Tarikh, masa & GPS dicetak terus pada gambar.
3. **Lebar / Panjang / Dalam:** selepas gambar, taip **ukuran sebenar dalam meter**, cth. `1.3` (koma pun boleh: `1,3`),
   maksimum 2 titik perpuluhan → **Simpan gambar**. Tanpa ukuran, gambar tidak boleh disimpan.
   Tersalah gambar? **Buang gambar ini**.
4. Gambar **disimpan serta-merta**. Ukuran dipaparkan di bawah gambar kecil (cth. **1.3 m**).
5. Anda boleh tambah lebih daripada minimum. Setiap jenis menunjukkan bilangan gambar dan minimum.
6. Bila kerja siap: **✔ Tanda kerja siap** (tersilap? **↩ Batal siap**).
7. **Nota**: tulis perkara penting (cth. *lokasi dianjak 5 m kerana paip*) → **Tambah nota**. Jangan ubah chainage — admin sahaja.

**Status gambar** di atas skrin tiang, cth. `Pegging ✓ · Trial Pit 3/4 · Installation 2/6`
(Installation: Progress dikira 4, Siap dan Ujian lampu 1 setiap satu). **Gambar lengkap** bila semua cukup.
Gambar bertanda **Ambil semula** atau tanpa ukuran tidak dikira — ambil gambar baru pada jenis itu.

**Simbol**: ✅ cukup · ◐ belum cukup · 📷 tiada gambar · 🔁 Ambil semula · `galeri` dari galeri · ⏳ belum dihantar.

**Tiada line?** Teruskan kerja. Bar atas: **⏳ N item menunggu line** → dihantar automatik → **✅ Semua disimpan**.
- Jangan padam aplikasi / data pelayar semasa masih ada item menunggu.
- "**Sesi log masuk tamat**" → **Log masuk semula**. Kerja anda selamat.
- Item **⚠️ gagal**: ketik bar atas → **Cuba lagi**, atau **Simpan gambar ke telefon** dan beritahu admin.

**Tunggu kelulusan**: belum boleh ambil gambar / tanda siap, tetapi boleh tulis nota.
**Sudah dipasang**: gambar tidak wajib (boleh ditambah).

## B. Untuk BOS (Boss)

Akaun Boss **lihat sahaja** (tiada gambar, nota, Siap, pelan atau pilihan laporan).

- **📊 Dashboard**: Kerja siap x/123 · Gambar lengkap · Perlu pasang · Tunggu kelulusan · Dalam proses · Belum mula
  (ketik kad untuk senarai); kemajuan EB/WB; senarai gambar belum lengkap (cth. *Trial Pit 3/4*), Ambil semula,
  CH belum tepat; aktiviti terkini.
- **📋 Jadual**: dibuka pada **Esok** (kerja yang dirancang esok). **Hari ini** / **Semua** juga ada.
  Ketik tiang → semua gambar ikut aktiviti; ketik gambar → saiz penuh, tarikh/masa, GPS (peta), ukuran, pengambil gambar.
- **📄 Laporan**: senarai laporan → **⬇ PDF** atau **⬇ Word**.

**Maksud status**: *Belum mula* tiada gambar · *Dalam proses* ada gambar, belum siap · *Siap* ditanda siap ·
*Gambar lengkap* semua jenis cukup gambar (dan ukuran). Status kerja dan status gambar berasingan.

## C. Untuk ADMIN

Semua yang pasukan boleh buat, ditambah yang berikut (perlu line internet):

### Pelan kerja
1. **📋 Jadual** → tab **Semua** (tab lalai admin) → tandakan ☑ satu atau lebih tiang (boleh tapis EB/WB/status dahulu).
2. Bar bawah: **📅 Rancang kerja** → pilih **tarikh** (lalai: esok) → pilih **aktiviti** (pilihan) → **Simpan**.
3. Satu tiang boleh ada beberapa pelan (tarikh/aktiviti berlainan). Pelan yang sama tepat tidak digandakan.
4. Ubah / buang: buka tiang → bahagian **Pelan kerja** → ✏️ → ubah tarikh/aktiviti atau **🗑 Buang pelan**.

### Pilih gambar untuk laporan
Pada setiap jenis gambar: **★ Pilih untuk laporan** → ketik gambar:
- Pegging, Korek, Lebar, Panjang, Dalam, Siap (siang), Ujian (malam): **tepat 1**
- Progress pemasangan: **tepat 4**, ikut susunan dalam laporan (1 → 4). Ketik gambar bernombor untuk buang.
→ **Simpan pilihan**. **Guna pilihan automatik** = gambar terkini yang tidak ditanda Ambil semula
(Progress: 4 terkini, lama → baru). Tile menunjukkan *Laporan: pilihan admin* atau *automatik*.

### Semak gambar
Ketik gambar → **🔁 Ambil semula** (pasukan perlu ambil semula) · **🚫 Sembunyikan** (tidak dipadam; boleh **👁 Tunjuk semula**).
Ukuran salah? Tanda **Ambil semula** dan minta pasukan ambil gambar baru dengan ukuran betul.

### Laporan (halaman gambar sahaja — borang RIN digabung sendiri)
1. **📄 Laporan** → pilih aktiviti: **Pegging / Trial Pit / Installation**.
2. Tandakan tiang (disusun ikut ID). Setiap tiang menunjukkan **✅ sedia** atau **⚠️ apa yang kurang**.
   **Tanda semua yang sedia** memilih tiang lengkap sehingga had.
3. **📄 Jana laporan** → jika ada tiang tidak lengkap, senarai amaran dipaparkan →
   **Teruskan tanpa tiang ini** atau **Batal**.
4. Siap dalam 1–3 minit. PDF dan Word disimpan dalam Drive `Solar Reports/` dan boleh dimuat turun oleh semua.

Had satu laporan (tab Settings → `ReportMaxPhotos` = 60): Pegging 60 tiang, Trial Pit 15, Installation 10.

| Laporan | Susun atur |
|---|---|
| Pegging | Jadual "PEGGING", 3 gambar sebaris, kapsyen ID tiang, "Total pegging : N nos" |
| Trial Pit | Satu blok setiap tiang "TRIAL PIT EXCAVATION WORKS": ID · WIDTH · LENGTH · DEPTH; ~3 blok satu halaman |
| Installation | Setiap tiang satu halaman: "…PROGRESS" (4 gambar) dan "…COMPLETED" (siang & malam) |

### Lain-lain
- **✏️ Edit tiang**: chainage, bound, tarikh rancang, kategori (cth. Tunggu kelulusan → Perlu pasang).
- **⚙️ Admin → Pengguna**: tambah Gmail, peranan, aktif/nyahaktif (berkuat kuasa serta-merta), buang.
- **⚙️ Admin → Aktiviti & jenis gambar**: tukar nama dan spesifikasi (minimum & susun atur laporan tetap).
- **⚙️ Admin → Log audit**: semua perubahan (gambar, Siap, pelan, pilihan laporan, laporan, pengguna).
